## The house rule

Ipcha reviews her own marketing. Every disclosure on every landing page passes a two-sentence test before it ships:

1. **Competitor test.** Could a competitor quote this on their own slide as a win? If yes, it&rsquo;s a benefit. Move it to the feature grid.
2. **Anti-fit test.** Does this name a scenario in which the reader should *not* adopt this product? If no, it&rsquo;s a characteristic, not a disclosure.

A card passes only when both answers are *yes — real concession* and *yes — real anti-fit*.

The rulebook, with bad-and-good examples: [`docs/IPCHA_DISCLOSURES.md`](https://github.com/nyxCore-Systems/nyxcore-landingpage/blob/main/docs/IPCHA_DISCLOSURES.md)
